    MANUAL ACCEPTANCE PROCEDURE

    Measure the conversation you actually hear.

    1. State the language, network, region, browser, hardware, and load profile. Test Telugu, Hindi, Indian English, and code-switching separately.
    2. Capture the caller’s microphone and actual speaker/headphone output on a shared recording timeline, using a loopback capture or external recorder. This page does not record either stream.
    3. Mark the caller’s actual speech end and the first meaningful audible agent response. Include endpointing, transport, and playback delay. Measure the gap for each turn and report p95 with the sample count.
    4. Report tool-dependent turns separately. While the agent speaks, interrupt naturally and listen for prompt cancellation and clearing of stale audio.
    Acceptance target: p95 under 500 ms. No measured endpoint latency or speech-quality result is established by this page.
